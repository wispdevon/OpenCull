Its dimensions are 2048 × 1365 and its displayed size is 527 KB. The second frame is `The One Camp Day 2—020.jpg`.

Capture settings: 2560 × 1440, 100% interface scale, Scene View, intelligent grouping and MobileCLIP visual grouping enabled, Loose grouping strength, 150 px frame strip and 170 px scene overview. Wait until analysis finishes before capturing. Scene numbers depend on loading the complete 82-photo set; the smaller retained subset will number its scenes differently.
