# Culltivate 0.7.1.1 — Smooth-scrolling hotfix

This hotfix addresses filmstrip rendering after using reference comparison.

## Changes

- Handle each filmstrip and scene-overview wheel event once, preventing blank
  thumbnails while preserving high-resolution fractional smooth scrolling.
- Keep horizontal input, modifier gestures, scrollbar navigation and linked
  comparison zoom working.
- On Linux/NVIDIA, paint tiles on the CPU while retaining GPU compositing.
  Physical Logitech G903 testing found substantially reduced image corruption,
  with minimal residual artifacting still reported. This is a mitigation,
  not a claim that every painting artifact is eliminated.
- Show CPU tile painting in the renderer diagnostics. An explicit
  `WEBKIT_SKIA_ENABLE_CPU_RENDERING=0` restores GPU tile painting for
  troubleshooting; other graphics profiles retain their defaults.
- Replace the README's broken repository-status badges and inline images with
  plain navigation and screenshot links.

Comparison remains local. Source protection, ratings, sidecars and AI defaults
are unchanged; CPU tile painting does not disable CUDA inference.

## Downloads and version

The release tag is **v0.7.1.1**. The internal package version is **0.7.1+1**,
which satisfies Rust/Tauri semantic-version requirements. Installer filenames
use the release number; package managers may display the internal version.

Linux x86_64 AppImage, Debian and RPM installers use an Ubuntu 24.04 baseline.
CUDA inference requires compatible NVIDIA drivers, CUDA 13.x and cuDNN 9.x;
CPU fallback remains available. Install updates manually: this fork has no
signed automatic-update feed.

macOS and Windows were not tested for this hotfix. GitHub Actions is disabled
for the publishing account; Linux installers are built locally.

## Validation

- 220 frontend tests and 34 launcher/importer tests; 384 CPU Rust tests
  (one ignored) and 386 CUDA-feature Rust tests (five ignored).
- Frontend build and CUDA native debug build.
- Native wheel regression: cancellation, horizontal/vertical input, line/page
  units, fractional accumulation, modifier keys and virtual cell coverage.
- Browser comparison regression: linked zoom/pan, navigation, replacement
  references, cropping/orientation, resizing and ordinary-loupe behavior.
- Native high-resolution wheel stress and physical G903 testing before,
  during and after comparison. Runtime worker inspection confirms CPU tile
  painting with the compositor still active.

All three installers passed package-version and CUDA/shared-library checks.
The AppImage's 179 ELF files require no newer than GLIBC 2.39. The actual
AppImage passed its full native self-test with five CUDA model sessions;
source fixture hashes and folder membership remained unchanged. The runtime
check used a disk-backed temporary directory after the system's full `/tmp`
prevented an initial extraction. Native video playback was not exercised.
Checksums are included in `SHA256SUMS`.
