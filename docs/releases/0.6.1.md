# Culltivate 0.6.1

Culltivate is Wisp's fork of OpenCull: a desktop workspace for reviewing shoots,
comparing frames and choosing what to keep. Photo processing stays on your
computer.

## Feature set

- **Review before copying.** Open folders or camera cards, combine card sources,
  select subfolders and resume saved review sessions. Review RAW/JPEG pairs
  together, then copy your selections without deleting card originals.
- **Fast photo review.** Browse embedded RAW previews in filmstrip, grid and
  scene views; zoom to faces, compare grouped frames, inspect EXIF and the
  histogram, and review video clips with local previews and native playback.
- **Marks and crops for your editor.** Apply stars, Pick/Reject flags, colour
  labels and non-destructive crops using compatible sidecars. Optional JPEG
  metadata writing is available in Settings and is off by default.
- **Local analysis.** Compare face sharpness, eye states, expression and gaze;
  rank frames within groups and reuse cached analysis. Advanced AI uses
  YOLO26n to find rotated faces and YuNet to locate their eyes.
- **Optional grouping and blur checks.** Use cached MobileCLIP visual grouping
  with Loose, Normal and Tight presets, or experimental motion-blur analysis
  with optional one-star/Reject marking for unrated detections.
- **A configurable workspace.** Choose Dark, Light, 18% grey or Wisp themes,
  local fonts, interface scale, home layouts, panel visibility and filmstrip
  sizes. Customize keyboard shortcuts and import or export preferences.

## What's changed since 0.5.0

0.5.0 was this fork's previous public release; the intervening 0.5.1 draft's
Linux packaging fix is included here.

- **The fork is now called Culltivate.** Existing OpenCull configuration and
  settings formats remain compatible.
- **Faces found at more angles.** Upstream's Advanced AI now finds faces turned
  sideways or upside down, then rotates face crops before judging eyes and
  expressions. Basic AI retains YuNet and the original rules.
- **Faster analysis.** Upstream reports roughly three times faster portrait
  analysis. On macOS, the face finder can use Core ML when measured throughput
  beats the CPU, and fall back when it does not.
- **Better Panasonic previews.** Newer Panasonic RAW files can now supply their
  full-size embedded preview.
- **More reliable Linux CUDA.** AppImage ONNX Runtime provider libraries are
  packaged where the app looks for them. YOLO can place supported operations
  on CUDA and unsupported operations on the CPU; CPU fallback remains available
  if CUDA initialization fails.
- **Performance details in Settings → AI.** Inspect YuNet/YOLO analysis chunk
  times, MobileCLIP grouping times and full-size preview orientation times.
  The log holds up to 500 entries in memory for the current session.
- **Upstream review improvements.** Video previews and playback, card-review
  completion, crop controls, light mode and readability at larger interface
  scales have been improved.
- **Development-only face-finder control.** Development builds expose an
  experimental YuNet/YOLO26n selector independent of the AI rules mode, with
  separate cached results. This selector is not exposed in release installers.

## Downloads and prerequisites

- **macOS Apple silicon:** use the `.dmg`. The app is not notarized.
- **Windows x64:** use the setup `.exe` or `.msi`. Installers are not code-signed.
- **Linux x86_64:** choose the `.AppImage`, `.deb` or `.rpm`. The release is built
  on Ubuntu 24.04 and requires a compatible system library baseline.
- Linux installers include CUDA support. GPU inference requires a compatible
  NVIDIA driver, CUDA 13.x and cuDNN 9.x; CPU fallback is available. macOS uses
  CPU/Core ML as described above; Windows uses CPU AI.
- Install updates manually. This release has no signed automatic-update feed.

MobileCLIP is optional, downloaded only on request and subject to Apple's
Machine Learning Research Model License, which covers non-commercial research
use. Review its terms before using it for paid work. Photos are not uploaded.

## Validation and limitations

The [tagged release build](https://github.com/wispdevon/OpenCull/actions/runs/39072765248)
passed frontend and Rust tests and produced installers on Linux, Windows and
Apple silicon macOS. Linux CUDA compilation and provider packaging checks,
macOS CUDA exclusion checks and the macOS desktop development startup check
also passed. These automated checks do not establish end-to-end camera-card,
external-editor or GPU runtime compatibility on every system. No additional
manual platform smoke tests were performed for this publication.

RAW rendering and HEIC decoding are not supported; RAW review uses the camera's
embedded JPEG. Visual grouping is limited to adjacent frames within a
three-second window. See [How it works](https://github.com/wispdevon/OpenCull/blob/v0.6.1/docs/HOW-IT-WORKS.md)
for preview, crop and editor compatibility limitations.
