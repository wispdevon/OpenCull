# Culltivate 0.7.1 — Reference comparison

Follow-up: physical high-resolution mouse testing found blank thumbnails and
image corruption still possible after this release's initial checks. See the
[0.7.1.1 hotfix](0.7.1.1.md) for the subsequent scrolling fix, NVIDIA mitigation
and remaining limitations.

Keep your current favorite visible while choosing between similar frames.

## New

- **Reference beside current:** press **Shift+R**, or use the toolbar comparison
  button, to pin the current still photo on the left. Browse other candidates
  on the right with the arrow keys, filmstrip or group shortcuts.
- **Linked zoom and pan:** inspect either pane and the other follows. Click,
  keyboard, wheel/pinch, face and box zoom share the same enlargement relative
  to Fit and the same relative position. Pixel-percentage badges can differ
  for different crops or resolutions.
- **Keep comparing as you browse:** new candidates and replacement references
  inherit the linked view. Click **Use as reference** to pin the current
  candidate, or **Close comparison**, **Escape** or **Shift+R** to return to
  the previous loupe, scene or grid workspace.
- **Normal culling controls:** rating, flag and colour shortcuts continue to
  target the current photo. The reference remains pinned when filters hide it
  from the filmstrip. Comparison needs no face detections.

The pin is temporary. Starting a crop exits comparison; videos can be browsed
as the current item but cannot be pinned. Existing sidecar behavior and card
review source protection are unchanged. Comparison itself writes no metadata.

## Fixed

- Rapid filmstrip scrolling could outrun thumbnail rendering, leaving blank
  frames during or after comparison. Visible cells now update with the scroll
  position; small movements retain the existing render margin.

## Downloads and platform status

Linux x86_64 AppImage, Debian and RPM installers use the Ubuntu 24.04 baseline.
Linux GPU inference requires compatible NVIDIA drivers, CUDA 13.x and cuDNN
9.x; CPU fallback remains available. Install updates manually; this fork has
no signed automatic-update feed.

macOS and Windows builds remain untested for this release. GitHub Actions is
disabled for the publishing account, so this release contains locally built
Linux packages only. The comparison feature uses the existing preview canvas
and introduces no platform-specific backend commands or new dependencies.

## Validation

Linux source checks passed 220 frontend tests and 34 launcher/importer tests,
382 CPU Rust tests (one ignored), and 384 CUDA-feature Rust tests (five
ignored). The CUDA desktop debug build and browser comparison checks passed,
including linked gestures, different crops/orientations, replacing the
reference, navigation, resizing and ordinary-loupe behavior.

The native scroll regression failed on the old code and passed with the fix.
On the Linux NVIDIA renderer, 160 rapid-scroll samples each before, during and
after comparison had no missing or unloaded visible thumbnails. Post-hover
screenshots and the full native self-test passed; source fixture hashes and
folder membership remained unchanged. Native video playback was not exercised
because the fixture folder contained only still photos.

The rebuilt AppImage passed its native self-test with five CUDA model sessions
ready. All three installers contain the CUDA and shared provider libraries.
The AppImage's 179 ELF files require no newer than GLIBC 2.39; checksums are
included in `SHA256SUMS`.
